# H1 module-system certificate rebuild

All **7,964 owners and 414,638 theorem axiom audits passed**. Both H1 closing
contracts are kernel-checked, exact, and hypothesis-free. Numeric compilation
used **155.174 CPU-hours**; closing added **12.59 CPU-seconds**.
The largest module used **5.987 GiB** peak RSS. The conservative
aggregate sampled bound is **160.028 GB**, below 270 GB.
The authoritative report and receipts are `/home/ubuntu/aklt/reports/REGEN_H1`.

`/home/ubuntu/aklt/reports/REGEN_H1/H1-module-system.patch` for the orchestrator

All 7,964 generated owner sources are under `CertData/H1/Generated/Batch/` and
`Bridge/`. They are excluded from Git. Their normal Lake artifacts are under
`.lake/build/lib/lean/CertData/H1/Generated/`. No legacy artifact is used.

the legacy production's exact 17 input hashes.

Run from `/home/ubuntu/aklt/rel/H1`, with the pinned prebuilt dependencies already
linked. Never update dependencies or rebuild Mathlib.

```sh
export PATH="$HOME/.elan/bin:$PATH"
export H1_REGEN_REPORT=/home/ubuntu/aklt/reports/REGEN_H1
python3 AKLT/Cert/H1/tools/production_bootstrap.py
python3 AKLT/Cert/H1/tools/production_receipts.py inputs \
  --output "$H1_REGEN_REPORT/data-input-receipt.json"
```

For a clean source installation directly from the numeric inputs (the destination
must have no generated sources), run:

```sh
python3 AKLT/Cert/H1/tools/production_reexport.py \
  --scratch /tmp/h1-fresh-export --install --report-dir "$H1_REGEN_REPORT"
```

This runs every original exporter and both bundling stages. The resulting
`data-only-production.json` is the complete build DAG. Without `--install`, it
checks every owner's bytes against the sources already installed. That complete
comparison has passed for this run. No legacy worktree is required for this route.

The faster retained-source route used for this campaign was:

```sh

  --legacy-root /home/ubuntu/aklt/wt/CERT_H1 \
  --legacy-manifest /home/ubuntu/aklt/reports/CERT_H1/phase3/production.json \
  --legacy-receipt /home/ubuntu/aklt/reports/CERT_H1/phase3/verified-production.json \
  --report-dir "$H1_REGEN_REPORT"
```

It verifies every retained source hash before applying the visibility-only
transformation. All its outputs matched full data-only regeneration byte for byte.
The original owner map is unchanged: 25 kinds, 7,964 owners, 7,962 patterns,
12,173 blocks, and 158,230 logical components.
